# Provenance

The certificate and checker origins are recorded in
[companion/PROVENANCE.json](companion/PROVENANCE.json). The 18 certificate files
retain the original supplied bytes. Source-archive and member names there are
historical provenance identifiers; the archives are not needed to run anything
in this repository.

The written mathematical sources are cited in the manuscript bibliography.
No bibliography PDF, proprietary data, source archive or external Python
dependency is bundled. The certificate checkers use Python's standard library.
Distribution terms for original repository material and the manuscript are
specified in [LICENSE_SCOPE.md](LICENSE_SCOPE.md).
